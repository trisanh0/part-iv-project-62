    About TEMPO +

    ML libraries use different data formats and interfaces. TEMPO connects them in one pipeline and evaluates each combination under the same conditions. It also caches extracted features and records time and memory.

    Measurements and race rules +

    Compute time covers feature extraction, selection and model training. Memory is peak RAM during extraction. Each pipeline uses one recorded measurement; the demo does not show run-to-run variation.

    For classification, compute time sets driving pace and prediction errors add a pit stop. Memory does not affect race position. Regression and forecasting races use compute time only.

    Driving cost = 1 + 0.12 × ln(1 + compute seconds). Pit cost = 4 × (1 − accuracy). Both use the same scale so the last car finishes at the chosen race duration. These are game rules applied to the measurements.
